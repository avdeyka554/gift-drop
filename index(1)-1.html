Настройки входа

Для настоящей авторизации нужно создать Telegram-бота, указать его username в Login Widget и отправлять полученный payload на backend для проверки HMAC-подписи. Токен бота нельзя хранить в HTML/JavaScript.

Данные и анимации: спасибо @GiftChanges за API (api.changes.tg) и CDN (cdn.changes.tg).
GIFT DROP — независимая демоверсия, не связанная с Telegram. NFT-владение, покупка, передача и TON-операции не выполняются. Для входа требуется серверная проверка Telegram Login.
